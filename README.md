# Netflix-Dashboard
Built a Tableau dashboard analyzing Netflix content by genre, release year, ratings, and geography
🎬 Netflix Movies & TV Shows Dashboard

An interactive Netflix Data Analysis Dashboard that explores the global distribution of Netflix content, ratings, genres, and release trends. This project transforms raw Netflix data into meaningful insights using data visualization and analytics techniques.

📊 Project Overview

This dashboard provides a comprehensive analysis of Netflix Movies and TV Shows across multiple dimensions, including country, genre, ratings, and release year. It helps uncover content trends, audience targeting patterns, and Netflix’s global expansion strategy.

🔍 Key Insights & Features

🌍 Total Movies & TV Shows by Country
Visualized using a world map to highlight Netflix’s global content reach.

⭐ Ratings Distribution
Breakdown of content ratings (TV-MA, TV-14, PG, R, etc.) to understand audience segmentation.

🎭 Top 10 Genres
Identifies the most popular genres such as Documentaries, Stand-Up Comedy, and International Movies.

📈 Content Growth Over Time
Year-wise trend showing the rapid growth of Netflix Movies and TV Shows.

🎥 Movies vs TV Shows Distribution
Clear comparison of content types available on the platform.

🧾 Title-Level Details
Displays selected title information including type, duration, rating, genre, release year, and description.

🛠 Tools & Technologies

Tableau – Dashboard design & visualization

Data Cleaning & Preparation – Structured and transformed Netflix dataset

Calculated Fields & KPIs – Content counts, trends, and distributions

🎯 Objective

The goal of this project is to:

Analyze Netflix’s content strategy

Identify trends in genres and ratings

Understand regional content distribution

Practice real-world data visualization and storytelling
